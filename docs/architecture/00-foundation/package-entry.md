# [00-07] __main__.py + __init__.py — 包入口

| 层 | 行数 | 上游依赖 | 被依赖 |
|---|---|---|---|
| 00-foundation | 9（6+3） | cli | 操作系统命令行（唯一启动路径） |

## 职责
`python -m stock_agent` 的薄入口：`__main__.py` 仅调用 `cli.main()`，`__init__.py` 仅声明 `__version__ = "0.1.0"`。不包含任何业务逻辑。

## 关键构件
- `__main__.main()` — 唯一启动路径，全部行为由 cli 决定。
- `__version__` — 0.1.0（与 pyproject.toml 一致）。

## 门禁 / 安全
无；安全语义全部在被调用的 cli 与各模块层。

## 备注 / 风险
无业务风险；列出此块是为满足"每个 .py 文件都有归属"的完整性强迫症。
