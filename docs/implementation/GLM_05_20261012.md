## 工作包与具体用户流程

用户的研究任务现在可以多轮进行：模型第一轮可提出只读数据请求（行情快照/新闻簇/证据摘要/批准指标计算，仅限已批准上下文内的引用），worker 用 Python 白名单 broker 执行并把结果回灌下一轮提示词；每轮重新运行完整外发治理与证据验真（不再只在开始时检查一次）；轮数预算 4（计划 §4.2 W10 上限），预算耗尽时如实 failed 而不把"临时摘要"伪装成最终结论。每轮调用前持久化尝试身份+提示词指纹，调用后持久化实际模型、用量与耗时（outbox 事件）。取消在每轮边界生效。

## 正负用例（先失败后实现）

10 用例先写并确认失败（6 failures + 2 errors），实现后全绿：
1. 中间轮意图结果回灌下一轮提示词（断言第二次调用 prompt 含动作名与标的）；rounds=2；outbox 有 research_round 事件；最终输出为第二轮。
2. 预算上限：10 个"继续要数据"响应只产生 4 次调用，第 4 轮后 failed，错误含 "round budget"。
3. 越权意图（未批准标的）→ 拒绝记录可见于下一轮提示词与轮记录（status=rejected）。
4. 治理与交付每轮重验（patch 计数 govern_egress 调用次数=轮数）。
5. 轮间取消：首次调用中置取消标志 → 第 2 轮边界转换 cancelled，只调用 1 次。
6. 非法 JSON → retryable failed，无更多轮。
7. 中间轮伪造证据引用 → 校验拒绝（引用不在批准集）→ failed。
8. 元数据缺实际模型 → model=unknown，request_model 保留请求值。
9/10. store 层：record_research_round 对 queued 任务 TaskTransitionError、对过期 token/错误 worker TaskFencingError；cancel_if_requested 无标志不转换、有标志转换 cancelled。

开发期修复记录：mock `side_effect=[callable]` 的元素是返回值不是调用（JSON 解析失败根因）；F02 顶层 usage 聚合回归（一轮修绿）；测试行情时间改动态近期值。
