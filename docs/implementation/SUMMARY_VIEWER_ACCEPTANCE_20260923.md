## 权限与失效控制

- 发放访问权限之前核对原生 Windows 账号；不存在的数据库、无效摘要或无权账号不启动监听。
- 只监听 `127.0.0.1` 随机端口；不占用现有工作台端口、不安装计划任务或常驻服务。
- 一次性随机入口在 URL fragment 中传给浏览器，页面立即移除；换取另一个仅存内存的短期令牌。
  项目文件、普通日志、终端输出不保存令牌；服务端只保存会话令牌哈希。
- HTTP 精确校验 Host/Origin/端口，不提供跨域权限、Cookie 或本地浏览器存储。
- 每次详情读取重新核对名册/限制名单、配置文件、任务版本、摘要状态及真实留存原件。
  变化后当前会话永久失效；恢复文件也不能复活旧会话。超时采用单调时钟，不滑动续期。
- 浏览器三秒轮询，失效/网络失败/关闭/到期时清除材料；晚到的成功响应不能重新填回材料。
  这不是瞬时推送撤权，也无法撤回已经被阅读、截图或被浏览器扩展复制的内容。
- 原文、标题、摘要和说明只按文本渲染，CSP 限制脚本、联网和嵌入；页面不加载远程素材。
- 不接受浏览器提交 actor/SID，不把服务进程账号当成浏览器用户；没有摘要决定或批准 HTTP 路由。

此处认证的是“CLI 本地账号发放的查看权限”，不是浏览器真人身份、真人在场或不可抵赖签名。
旧任务面板的自报 actor 反馈、CLI `show` 的本地文件访问边界没有被包装成企业认证。
受保护机构操作仍须独立身份体系、安全评审和真实人工授权。

## 实际验证

测试凭据和人员全部为**合成夹具**，保存在 OS 临时目录。原件通过真实 importer 生成，
信号、任务、摘要、权限和来源校验使用真实代码；只替换原生 SID 查询结果，不关闭授权检查。

| 验证 | 结果 |
|---|---|
| 隔离 `test_summary_viewer.py` | **22/22 OK**，8.606 秒 |
| 隔离 `test_summary_review.py` | **23/23 OK**，6.013 秒 |
| 最终 Chromium 独立浏览器驱动 | **6 组通过**，退出码 0 |
| 最终全量受保护回归 | **1035 项，94.170 秒，errors=14 / skipped=2，退出码 1** |
| 文件空白检查 | 跟踪文件 diff 检查与新增源码行尾检查通过 |

全量结果没有断言失败。14 个错误记录仍全部来自已知的宿主守卫拒绝原生子进程：
工作台 PowerShell 解析/生命周期、Z002 脚本解析、Z003 junction 测试。
错误记录包含 subtest，不能简单用 1035 减去 14 来宣称通过用例数。
原生验收仍须在可销毁的 Windows 隔离环境执行，不放开宿主守卫。

本轮第一遍全量回归曾有一个新增测试断言失败：另一任务夹具使用相同案件和输入，
被正常幂等逻辑返回了已有任务。已改为独立案件 ID，并增加 `RECORDED` 与不同 task_id
断言后再跑专项和全量；未改生产幂等规则来迎合测试。
