## 4. 行为设计（与缺陷对应，F12「正文未形成研究链」）

- 「evidence_excerpts 只接 text/plain、HTML 解析未接生产」→ 摘录层接入 extract_body：HTML 文档（vault 白名单早已允许）首次可被定位、验证、绑事实。
- 定位器完整性：selector 六字段不变；版本链使 HTML 摘录的验证必然回放同一解析管线；source_text_sha256 对归一化文本计算——旧 text/plain 选择器的三个哈希全部逐字节不变（回归证明）。
- 个人 namespace：隔离通过**根隔离**实现（不同根=互相不可寻址，双向测试证明），不通过标志位——不存在「忘记检查 namespace 字段」这类漏洞面。
- 机构边界：个人导入的 stamp 明示 `institutional_admission=NOT_REQUESTED`；机构投影对个人导入完全不可见（空投影断言）。
