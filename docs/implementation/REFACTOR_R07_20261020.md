## 1. 包 ID 与用户行为

R07。

1. **五根冻结布局**：`runtime_layout.RuntimeLayout`（frozen dataclass）一次性解析 `APP_CONFIG_ROOT / APP_STATE_ROOT / APP_EVIDENCE_ROOT / APP_REPORT_ROOT / APP_TEMP_ROOT`（env 优先 → config `runtime_layout` 段 → PROJECT_ROOT 缺省），显式传给服务；线程共享只读快照，生产路径不再经 contextvar 推断（A35）。
2. **路径安全**：`resolve_within_root`（仅单段名：拒绝分隔符/`..`/绝对注入/盘符）+ `ensure_within`（resolve 后必须仍在声明根内，symlink 中转逃逸同样被拒）；中文/空格路径按原样映射不折叠大小写（A36 的 O 层半；Linux 大小写半归 R08 的 C 层）。
3. **时钟契约**：持久时间统一 UTC（`utc_now_iso` 恒带 +00:00）；**预算日/业务日 = 显式 Asia/Shanghai 日历日**（上海午夜为界，与宿主时区无关——`2026-10-20T17:00Z` 归属 21 日）；naive 输入与未知时区名拒绝；时钟偏差单一定义（±300s，ok/skewed 不静默校正）。
4. **预算日接线**：`store.reserve_model_attempt`（事件时间戳解析判日，替代宿主本地日期前缀匹配）、`budget_guard.model_calls_today`、`connector_runtime` 配额日键——三处统一走 `business_date`。
5. **跨平台解释器候选**：`DEFAULT_PYTHONS` 同时携带 Windows（Scripts/python.exe）与 Linux（bin/python）布局；本 OS 缺失的布局记为信息性 `skipped_candidates`，绝不成为阻断（必修 minor 校验仍 fail-closed）。
6. **备份布局快照**：backup manifest 新增 `runtime_layout` 字段（五根快照）——跨根恢复时映射可核，历史存档绝对路径不被改写。
7. **遗留路径映射**：`PathMap.from_layout` —— 旧绝对路径 → 当前根的**只读重定位**（stored 原文永不改，哈希历史不动）。

## 4. 行为设计（与任务书逐条对应）

- 「分别设置并冻结传入」→ frozen dataclass + `resolve_layout` 单次解析；服务接收显式布局对象（R08 起接线启动参数）。
- 「禁止线程依赖测试 contextvar 推断生产路径」→ 布局解析是纯函数、无 contextvar；`project_path` 的 contextvar 仍只在测试上下文生效（生产路径 `PROJECT_ROOT` 直落）。
- 「旧绝对路径保留原值，artifact ID/path map 解析，不改写历史哈希」→ `PathMap` 只做读侧重定位；stored 文本原样返回。
- 「UTC 持久 + 业务日/预算日/交易时隙显式沪时」→ 时钟模块三函数即权威；三处预算计数已切换；交易时隙（休市/恢复）随 R09 计划时隙验收落地（任务书专项归 R07-R10 联合）。
- 「未知时区拒绝」→ naive datetime 与未知 tz 名都抛 `LayoutError`，绝不猜测。
