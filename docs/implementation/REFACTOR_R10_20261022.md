## 4. 行为设计（与缺陷对应，F17）

- 「board 接收 caller actor，store 仅要求非空」→ 会话模式使主体**只**来自服务端会话；表单字段的出现本身就是拒绝理由（比忽略更强——攻击者无法探测合并语义）。
- 服务标识判定 = AUTOMATED_ACTOR_PREFIXES ∪ 本项目实际服务凭证格式标记（`dify:` 前缀正是 R03 审计账本里平台动作的 actor 形态）。
- 提供方认证在登录时一次性完成（Windows 桥校验 SID+名册绑定）；会话只携带结果，有效期后必须重认证。
- board 的 CSRF（既有）+ loopback Host/Origin（既有）叠加会话层——三层各自独立失效仍安全。
