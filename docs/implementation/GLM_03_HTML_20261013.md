## 工作包与用户流程

HTML 格式的留存证据字节（公告页存档等）现在能提取**可见正文**：标签/属性丢弃、**script/style/noscript/template 内容整块丢弃**（不执行任何脚本、不加载任何外部资源）、HTML 实体解码（含中文数字实体）、空白折叠为单空格；块级标签 (`<p>/<tr>/<td>`…) 转为词边界。与 UTF-8 路径同一套显式状态契约：ok/empty/not_utf8/too_large/unsupported_content；大小上限不变（2 MiB）。HTML 探测升级：`<html`/doctype 标记之外，任何以标签形式开头（`<字母`/`<!`/`</`）的字节流按 HTML 处理——`<p>正文</p>` 这类无根标记片段不再误判为纯文本。
