# GLM-09 交付报告（2026-10-12，切片 2）：同题聚类与跨周期冷却

执行：GLM。范围：触发契约补完——同一新闻多渠道转载只开一个研究任务（同题聚类），标的冷却与故事冷却跨调度周期生效（从近期任务推导状态）。

## 工作包与具体用户流程

- **同题聚类（默认开启）**：标题归一（剥离 `【快讯】` 类前缀装饰、去标点/空格/大小写、取前 60 个有效字符）+ 标的集合构成故事键。同一周期内同键多来源信号只开一个任务，赢家按"官方公告 > 新闻、优先级高、发布早"选出；其余计入 `skipped_by_cluster`（不静默丢）。**内容修订（version>1）永不聚类**——更正必然重新打开研究。
- **跨周期状态**：`symbol_cooldown_minutes` 与 `cluster_cooldown_minutes`（默认 0=关）从"近期任务的 created_at + origin 标题/标的"推导冷却表（`_seed_cross_cycle_state`，最优努力：坏时间戳不冷却，同键取最新时间戳）。跨周期命中同故事 → 整故事跳过；同标的异事 → 触发策略冷却拒绝。
