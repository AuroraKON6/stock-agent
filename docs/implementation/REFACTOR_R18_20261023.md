## 1. 包 ID 与用户行为

R18（O 层；官方 MCP SDK 采用与真实服务器对接 = NOT_RUN）。

1. **连接器策略层**（`connectors/policy.py`）：fail-closed manifest（未知字段/非法传输/非 HTTPS 远端/缺失受众全拒）；**工具可见性=白名单**（A81：服务器多广播的工具是不可见的新面，绝不自动生效）；**调用方凭据禁运**（A82：Authorization/X-API-Key/Cookie/proxy-authorization 出现在调用参数即拒绝，连接器只以自己的策略凭据+记录受众认证）；**端点钉扎**（A83：构造期解析 DNS——私网/回环/链路本地/组播/保留地址全拒，未解析也拒）。
2. **MCP 薄客户端**（`mcp_client.py`）：initialize→tools/list→tools/call 的 JSON-RPC 公共面（协议版本不匹配即握手失败）；**工具结果大小封顶**（A84：超限=有界拒绝，载荷丢弃不解析）；**注入文本=数据**（A85：毒文本逐字透传、工具集不扩张）；**调用中断连**：已发送后断连→`connection_lost_after_send`+人工对账提示，绝不静默重试（与 R02 语义一致）；`MemoryMCPTransport` 进程内假服务器承载全部规则（零网络零子进程，守卫友好）。
3. **HTTP 连接器**（`http_client.py`）：exact-origin POST——构造期 DNS 钉扎 + 请求期凭据仅自持 + **3xx 一律拒绝不跟随**（重定向=目的地变更）+ 响应封顶 + 畸形有界失败。
4. **支持矩阵（A80）如实报告**：`mcp_stdio`/`http` = VERIFIED_O（进程内假）；`mcp_http`/`mcp_sse`/官方 SDK = NOT_RUN（SDK 是新运行时依赖，需来源/许可证登记+锁定安装，未做就不冒充支持）。
