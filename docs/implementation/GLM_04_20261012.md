## 正负用例（先失败后实现）

`tests/test_task_intake.py` 先写并确认失败（ModuleNotFoundError），实现后 13/13。覆盖：
- 同事件两次 → DUPLICATE、1 任务、1 消费行；事件键与 `event_identity` 一致；payload 含 origin 块且保持 public。
- 修订（version=2）→ 新任务、supersedes 指向旧任务、2 消费行；不同 purpose 是独立泳道。
- 崩溃窗口：任务已提交但消费行缺失 → 重投递收敛账本（DUPLICATE + 补消费行）；消费行与任务创建原子（orphan=0）。
- 重扫：2 信号 → 2 任务；第二次重扫 created=0/skipped=2；迟到信号（发布早于首次扫描）不被高水位丢弃；example/internal 信号被选择器拒绝且不建任务。
- 问题入口：同问题 DUPLICATE、不同问题新任务、origin.kind=question。
- CLI：`task-rescan` 首跑 created=1、重跑 created=0/skipped=1、任务数恒为 1。
