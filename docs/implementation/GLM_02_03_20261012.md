## 正负用例（先失败后实现）

四个测试文件先于实现编写并确认 ModuleNotFoundError 失败，随后实现至全绿。负例覆盖：

- 时间：缺失不填充、未来保留并标记、不可解析原样保留、naive 时间必须显式 default_tz（记 assumed）、observed 早于 source 记 ordering_violation、fetched_at 必填。

- 提取：空/超大/非 UTF-8/控制字符均显式状态且无 text 字段、扫描 PDF=needs_ocr、有文字层 PDF/HTML=unsupported_format（不伪造）。
- 事实：篡改 selector 拒绝、amount 缺数值/非法单位拒绝、computed 必须引用既有 fact_id、opinion 类型拒绝、超长 statement 拒绝。
