## 工作包与具体用户流程

一条命令/一个 GET 回答"有什么在等我"：

- **awaiting_human**：研究任务提出的人工问题（问题/原因/选项/更新时间/已等待分钟数），**最旧优先**——先处理等得最久的；
- **blocked**：被治理阻断的任务（拒绝原因摘录 + 处置入口说明——CLI human-response/task-cancel；页面写路径待 ADR-002 验收）；
- **review_queue**：复核队列的 pending 计数（读其自身 latest 投影；无投影时 available=false 如实报告）；
- **counts**：两类计数。

处置动作**不在本视图内**：保持既有已验证入口（CLI/单 POST 路由），不批量批准、不绕过权限。
