# GLM-09 交付报告（2026-10-12）：研究触发契约

执行：GLM。范围：GLM-09 的核心离线契约——哪些事件可以开启研究任务（阈值/封顶/冷却/修订规则），确定性、零 LLM。任务引擎成为生产权威前的必要门槛：此前 rescan 会为每条合格公开信号建任务。

## 工作包与具体用户流程

事件进入任务引擎前先过触发策略（`task_runtime.research_trigger` 配置）：

- **公告（filing）恒触发**（无论优先级——公告天然高价值）；
- **新闻需至少 P2**（`news_min_priority`，默认 P2，可配置 P0-P3）；
- **每标的每周期封顶**（`max_per_symbol_per_cycle`，默认 0=关）——防止单一标的刷屏任务队列；
- **标的冷却窗口**（`symbol_cooldown_minutes`，默认 0=关）——同一标的短时间内不重复触发（周期内状态，跨周期冷却需查询历史任务，列为后续项）；
- **内容修订（content_version>1）恒触发**——更正公告必须重新打开研究，任何封顶/冷却/优先级规则都不能拦它；
- 每个决定携带机器可读 reason；被跳过的事件**计数报告**（`skipped_by_trigger`），不静默丢弃。
