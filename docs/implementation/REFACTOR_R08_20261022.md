5. **compose fail-closed**：`STOCK_AGENT_TAG` 未按 digest 设置时 compose 直接拒绝启动；`read_only` rootfs + `cap_drop: ALL` + `no-new-privileges`。
6. **pyproject**：`requires-python >= 3.11`（与 3.11/3.12 验收基线对齐，原 >=3.8 为 F18 指出的漂移）。
7. **release_audit 无 .git 分支**：缺 Git 时唯一可替代的审阅身份是完整验证通过的 provenance 链（降级为 warning + 显式记录 source_commit/dirty）；证据不全时 blocker 维持。Linux 锁纳入审计候选。
