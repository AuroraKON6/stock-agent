# Signal Analysis

1. Separate observed facts, model inference, and unknowns.
2. Cite exact supplied field paths for every material conclusion.
3. Set direction, confidence, horizon, risks, and falsification questions.
4. Lower confidence when provenance, freshness, or independent confirmation is weak.
5. Export only review and audit suggestions. Never produce executable trading actions.
