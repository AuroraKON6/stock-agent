# Pi Research Skill Methodology Notices

The production project does not install or execute code from the repositories
listed below. Selected research methods were rewritten as small, no-tool,
project-controlled prompt assets. Source repositories remain pinned in
`config/pi_skills.json`, and exact local content is locked in
`config/pi_skills.lock.json`.

The corresponding Apache License 2.0 texts are available in the pinned source
checkouts under `output/skill_audit/sources_20260823/` and in each upstream
repository.
