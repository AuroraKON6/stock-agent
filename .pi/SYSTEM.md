# A-share Research Boundary

This project is a research-assistance system. Use project skills only for
analysis, challenge, synthesis, and review preparation. Never execute trades,
orders, position changes, publication, assignment, approval, activation, or
configuration changes. Protected actions require distinct authorized humans.

Do not bypass data classification, source provenance, freshness, restricted
list, prompt-injection, evidence-grounding, review-queue, or audit controls.
Do not treat a free data source as licensed or internally approved.
