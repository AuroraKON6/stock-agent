# A股投研系统 OpenClaw 技能包集合

本目录包含了为A股投研系统收集的高质量OpenClaw技能包。

## 已下载技能包列表

### 1. akshare-data
- **功能**: 基于AkShare库的中国金融市场数据访问
- **用途**: 获取A股、港股、美股、期货、基金和宏观经济指标数据
- **覆盖需求**: 统一接入数据源

### 2. stock-analysis
- **功能**: A股/港股量化分析，计算12项技术指标
- **用途**: MA、RSI、MACD、KD、布林带、ATR等技术指标分析
- **覆盖需求**: 量化分析、技术分析

### 3. stock-monitor
- **功能**: 全功能智能股票监控预警系统
- **用途**: 成本百分比、均线金叉死叉、RSI超买超卖、成交量异动等7大预警规则
- **覆盖需求**: 监控市场主题、板块和风险信号

### 4. stocksight
- **功能**: 股市情感分析
- **用途**: 基于Twitter/新闻的情感倾向分析，预测短期股价走势
- **覆盖需求**: 社媒情感分析、新闻舆情监控

### 5. auto-data-analysis-claw
- **功能**: 自动化数据分析
- **用途**: 数据去重、打标签、优先级排序
- **覆盖需求**: 去重、打标签和优先级排序

### 6. financial-report-render-claw
- **功能**: 财务报告渲染
- **用途**: 将数据分析结果转化为精美、可汇报的正式报告文件
- **覆盖需求**: 分析结果沉淀为日报、预警或仓位建议

### 7. historical-data-compare-claw
- **功能**: 历史数据对比
- **用途**: 持续复盘哪些信号真正有效
- **覆盖需求**: 持续复盘、信号有效性验证

### 8. strategy-advisor-claw
- **功能**: 策略顾问
- **用途**: 提供投资建议和仓位管理策略
- **覆盖需求**: 分析结果沉淀为仓位建议

### 9. dashboard-skill
- **功能**: BI数据看板生成
- **用途**: 生成交互式数据可视化仪表板
- **覆盖需求**: 分析结果可视化、监控大屏

### 10. powerpoint-pptx
- **功能**: PowerPoint生成
- **用途**: 生成专业的PPT报告
- **覆盖需求**: 分析结果沉淀、汇报材料生成

## 使用建议

1. **数据采集层**: 使用 akshare-data 获取A股实时行情、历史K线、财务指标
2. **监控预警层**: 使用 stock-monitor 和 stocksight 监控市场动向和舆情
3. **分析处理层**: 使用 stock-analysis 和 auto-data-analysis-claw 进行量化分析
4. **报告输出层**: 使用 financial-report-render-claw 和 powerpoint-pptx 生成报告
5. **复盘优化层**: 使用 historical-data-compare-claw 验证策略有效性

## 安装说明

这些技能包已经下载到当前目录，OpenClaw会在下次启动时自动识别它们。

如果需要单独安装某个技能，可以在OpenClaw中使用以下命令：
```
/skills install <skill-name>
```
